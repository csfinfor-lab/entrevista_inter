# Uso de IA no projeto

O README do desafio exige que prompts, pesquisas e códigos de referência gerados com IA sejam
anexados e commitados. Registre aqui, **no mesmo commit** do código gerado:

- `AAAA-MM-DD-<dev>-<assunto>.md` — prompt usado + resumo do que a IA devolveu + o que foi aceito/alterado.

Regra da equipe: quem commita precisa saber explicar cada trecho.

## Índice

- [prompts.md](prompts.md) — todos os prompts do usuário, na íntegra, em ordem, com o resultado de cada um
- [prompts-agentes.md](prompts-agentes.md) — prompts enviados aos subagentes (Dev 1, 2 e 3)
- `2026-10-08-dev*-*.md` — registro por desenvolvedor: o que foi gerado e o que foi verificado
